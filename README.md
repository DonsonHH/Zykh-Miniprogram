# 智药康护微信小程序

智药康护是面向家庭照护者的微信小程序，与 QSM368ZP-WF 家庭健康终端和微信云开发后端协同工作。当前版本聚焦“看清今天要处理什么、管理三类家庭药品、查看健康记录与用药风险”，不在移动端伪造终端尚未回传的执行结果。

> 当前产品已取消 23 个独立药仓、舵机开仓和自动出药。旧仓号只用于一次性迁移分类，不再是用户操作或云端药品身份。

## 功能

- 首页：聚合当天照护焦点、药品风险、提醒、问询和最近健康动态。
- 药库：按“日常用药、外用护理、慢病处方”三个药柜查看板端当前 23 种药品、有效期和明确余量状态。
- 问询：按家庭成员查看已完成问询摘要，并按需读取过程详情。
- 照护：统一展示健康测量和用药风险，不再读取或展示旧取药记录。
- 用药风险：集中显示“哪位家人不宜使用哪种药”，并合并同一人物与药品的重复核验。
- 家人：查看服务对象、计划、风险摘要、授权设备和个人历史。
- 健康测量：展示心率、血氧、体温及明确的测量归属。
- 账号授权：通过 `GET_MY_DEVICES` 获取可访问药箱；Release A 只服务既有有效授权，不开放自助配对。

## V1 设计原则

- 小程序是照护端，Station 是现场执行端；硬件事实以 Station 回传为准。
- 每页只突出一个当前焦点，重复操作改为整卡或整行点击。
- 库存使用 `STOCKED / DEPLETED / UNKNOWN` 显式状态，不从数量猜测事实。
- 人物数据按稳定 ID 与 `personaGeneration` 隔离，不按姓名合并。
- 体征、问询、风险事件和命令始终固定在发起请求时的设备作用域。
- 小程序不直接监听受保护集合，也不提供远程开柜、自动出药、批准或放行入口。
- 药品由终端扫描溯源码后入库；小程序读取终端同步结果，不维护物理仓位。
- 当前阶段内置 23 种药品的展示参考资料，但可见集合只由板端 finalized manifest 决定。具体映射见 [板端 23 种药品参考清单](docs/BOARD_23_MEDICINES.md)。

完整页面、数据归属和同步闭环见 [小程序逻辑归档](docs/MINIPROGRAM_LOGIC_ARCHIVE.md)，界面与交互约束见 [DESIGN.md](DESIGN.md)。

## 项目结构

```text
miniprogram/            小程序业务代码、页面、组件和领域模块
cloudfunctions/api/     微信云函数 API
tests/                  Node.js 行为与契约测试
tools/                  小程序 UI 静态校验工具
docs/                   兼容、同步与部署文档
project.config.json     微信开发者工具公共项目配置
cloudbaserc.json        CloudBase CLI 公共配置
```

本仓库不包含 Station 主程序、设备密钥、数据库、个人开发者配置或构建缓存。

## 开发环境

- 微信开发者工具 Stable
- 微信基础库 `3.16.1`
- CloudBase 云函数 Node.js `20.19`
- 本地测试 Node.js 20 或更高版本

## 本地运行

1. 克隆仓库。
2. 使用微信开发者工具导入仓库根目录。
3. 确认 `project.config.json` 中的小程序 AppID 与当前账号匹配；若需要使用自己的 AppID，只在本地修改或使用私有项目配置，不要提交凭据。
4. 选择或创建 CloudBase 环境，并按 [部署说明](docs/DEPLOYMENT.md) 离线验证后分阶段部署 `cloudfunctions/api`。
5. 编译小程序，在“家人”页选择账号已获授权的药箱。Release A 不提供手填设备编号或自助配对回退。

## 云端与 Station 兼容

本版本对应 CloudBase schema revision `3.0-three-box-library`。当前代码实现的是 Release A：先恢复设备心跳、账号已有授权和板端药库快照。

- `PING` 必须精确声明 Release A 七项能力；缺项或版本不符显示“云端版本待升级”。
- 人物、计划、问询、体征、记录和远程命令在 Release A 失败关闭，并显示资料迁移状态。
- 只有超过 60 秒的合法历史心跳显示“等待药箱连接”；加载、未授权、版本不兼容和读取失败均有独立状态。
- 网络或权限失败不得呈现为“0 条风险”、空药箱或假在线。

板端部署包、设备密钥和 SQLite 不属于本仓库。Station 必须实现有 lease/fencing 的版本化快照协议，持续上报服务端心跳，并为每条药品提供稳定 `medicineId` 与 `storageBox`。具体见 [三盒架构迁移说明](docs/THREE_BOX_MIGRATION.md)。

> 当前仓库改动不代表云端已经部署，也不代表真实板端已经恢复同步。必须按部署文档完成备份、云函数验证、板端配套升级和真机验收后，才能宣告联机完成。
