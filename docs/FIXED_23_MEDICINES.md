## 使用规则

1. 原系统编号仅用于识别和一次性迁移，不在小程序用户界面展示。
2. 固定资料通过药品稳定 ID、条码、准确名称或旧编号匹配，优先使用稳定 ID。
3. 新包装的厂家、规格、条码与现有资料不一致时，以 Station 实扫数据为准并重新核验说明资料。
4. 处方药、抗菌药以及涉及过敏史、慢病或肝肾功能风险的药品，不因出现在家庭药库中就代表适合某位家庭成员使用。
5. 小程序只展示风险和说明资料，不替代医生诊断、处方或药师指导。
